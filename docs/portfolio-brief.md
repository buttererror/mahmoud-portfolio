# Portfolio Brief

This document holds product and content direction for Mahmoud Ahmed's portfolio. It is a working brief, not a locked specification. Agents should use it as the current default and raise tradeoffs when a better direction appears.

## Project Goal

Build a professional portfolio website for Mahmoud Ahmed, a Front-End Developer focused on React.js, Next.js, TypeScript, dashboards, SEO, performance optimization, frontend deployment, and reliable product delivery.

The portfolio should support job applications, LinkedIn, GitHub, and resume refinement. It should be a proof-of-work website for recruiters and hiring managers, not a fancy animation project.

## Public Safety

The portfolio must be public-safe.

Do not expose:

- Private company code.
- Internal workflows.
- Private architecture.
- Exact company tech stacks.
- Private dashboard screenshots.
- Credentials, private APIs, or confidential implementation details.
- Phone number.

It is acceptable to use public-safe categories, broad domains, approved public links, and generalized project descriptions.
